# Machine learning in healthcare

This repository contains a collection of machine learning projects in healthcare field including survival analysis

## Projects

1. **Survival Analysis**  
   Comparing survival analysis on NCCTG Lung Cancer Data using Kaplan-Meier survival curves and Cox Proportional Hazards (CPH) model. 

2. **Observational studies of causal effects**  
   Perform inverse-propensity weigthing (IPW) estimation of the average causal effect (ACE) of mothers smoking during pregnancy on children being born with low birth weight.
